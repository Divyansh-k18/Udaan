\# Udaan



Udaan is an accessible online examination and practice platform designed to help visually impaired candidates independently prepare for and participate in digital examinations.



\## Project Status



Initial project setup.



\## Planned Technology



\- Frontend: React

\- Backend: FastAPI

\- Version Control: Git + GitHub

\- Accessibility: WCAG 2.1 AA and WAI-ARIA
